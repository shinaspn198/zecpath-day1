# Day 4 – Data Understanding & Structuring

## Objective

The objective of Day 4 was to understand hiring data by converting unstructured resumes and job descriptions into structured AI-ready formats. This process is essential for AI-powered recruitment systems, resume parsers, and candidate-job matching applications.

---

# Tasks Performed

- Analyzed a sample candidate resume.
- Studied an AI/ML Engineer job description.
- Identified candidate skills, education, experience, and certifications.
- Extracted job requirements and responsibilities.
- Designed structured JSON schemas.
- Created AI data entities.
- Performed resume-to-job matching.

---

# Deliverables

## 1. Resume Structured Schema

Created a standardized JSON schema to store candidate information including:
- Personal details
- Skills
- Education
- Experience
- Certifications
- Projects

---

## 2. Job Description Schema

Created a structured JSON schema containing:
- Job title
- Company
- Location
- Experience required
- Education required
- Required skills
- Preferred skills
- Responsibilities

---

## 3. AI Data Entity Design

Designed reusable entities:
- Candidate Profile
- Job Profile
- Skill Object
- Experience Object

These entities can be used in AI-powered hiring systems and resume parsers.
