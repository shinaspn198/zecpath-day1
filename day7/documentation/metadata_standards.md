# Zecpath AI Metadata Standards Document


## Overview

Metadata helps Zecpath AI track, organize, and manage all AI-generated and stored data.

Every AI data record should contain standard information about:

- Candidate
- Job
- AI model
- Processing time
- Data status


# Required Metadata Fields


## 1. Candidate ID

### Purpose

Unique identifier for every candidate.

### Example

```json
{
 "candidate_id": "C001"
}
